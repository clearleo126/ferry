> **一句话结论**：互联类型与集群一致（**无 NVLink、无 P2P、host-staged**），
> **x16 卡对的 24MB 端到端迁移带宽 17.6 GB/s ≈ 集群 4×3090 的 17.9 GB/s（−1.7%）**，

## 2. 三关结果

### 关 1：逐对 host-staged（`probe`，2MB 粒度量级）
| 路径 | batched | non-batched | 备注 |
|---|---|---|---|
| 0↔2 / 0↔3 / 2↔3 | 11.22–11.28 GB/s | 11.26–11.27 | x16↔x16 |
| 0↔1 / 1↔2 / 1↔3 | 7.70–7.80 GB/s | 7.64–7.82 | **含 GPU1（x8）** |

### 关 2：粒度扫描（`probe --bw`，0→3，单流）
| 粒度 | GB/s |
|---|---|
| 16 KB | 1.46 |
| 256 KB | 8.20 |
| 1 MB | 10.09 |
| 4 MB | 11.62 |
| 16 MB | **12.15** |

⇒ ≥1MB 后 ≈11–12 GB/s 并趋平，与集群参考一致。

### 关 3：`bench_comm`（dev=0，4×2MB slot，256MB）
```
channel 16.26 GB/s | p1-batched 11.41 GB/s | ratio 1.425 (PASS >=0.95x)
correctness PASS
```
- 与集群参考（channel 19.15 / p1 10.36 / ratio 1.85）比：**channel −15%、p1 +10%、ratio −23%**。
- **判定：不按 ratio 退机。** 理由：真正用于迁移的量级（24MB 端到端）与单流饱和都和集群同量级；
  ratio 的偏离来自 channel 单项（本机 channel 偏低、p1 偏高），不改变 host-staged 机制。
  但**绝对吞吐类论断须标注本机平台**，不与 3090 主数字混表。

### 关 4（补充）：24MB 迁移路径微基准（`run_mig_path`，reps=10，full 轴）
| 源→目的 | dual_full 24MB | host_full 24MB | 判定 |
|---|---|---|---|
| 0→2（x16↔x16） | **1.433 ms / 17.6 GB/s** | 1.009 ms / 24.9 GB/s | PASS |
| 0→1（x16↔x8） | 2.134 ms / **11.8 GB/s** | 1.878 ms / 13.4 GB/s | PASS |

与集群 `kvmode` 表（full 24MB = 17.9 GB/s；delta batched = 16.6 GB/s）对齐：
**x16 卡对同量级，GPU1 卡对 ≈0.67×**。

## 3. B_ref 取值建议（用于 WlA 回放）

- **x16 卡对（0/2/3 之间）：B_ref = 17.6 GB/s**（24MB full 实测）。
- **涉及 GPU1：B_ref = 11.8 GB/s**；4 卡同跑时若只给一个全局值，`--mig-bw 17.6`
  会低估 GPU1 侧成本 ≈1.5×，须在结果里标注，或以 `--gpus 0,2,3` 做同构三卡对照。
- κ 保持策略语义（默认 3.0）不变；换成 B_ref=17.6 后的工作点
  `κ·V/B_ref` 与集群 3090（16.6）几乎相同 ⇒ 可直接对照。
- 4×3090 的 `B_ref=16.6` 来自 delta-batched 口径，本机 full 口径 17.6、delta 8MB 15.5，
  差异 <7%，不构成跨平台障碍。

## 4. 对 L1（真实 trace）的影响与限制

1. **trace 抓取只需 1 张卡**：建议固定 GPU0（x16），抓取性能不受 GPU1 影响。
2. **回放的 4 卡异构**是真实平台属性，不是噪声；报告需区分「x16 三卡」与「含 GPU1」，
   否则迁移成本的可比性会被一个节点拉低。
3. **250 W 功耗墙**：真实 decode 的 `t_step` 会在持续负载下降频，
   本机测得的步时只能作 4090 上界；论文里必须写平台功耗设置。
4. 本机 `/workspace` 非持久 + 31GB 盘：模型/trace 用完即同步；
   不要把这里当主实验平台，只作**第 4 平台/跨平台证据**。

## 5. 复现命令

```bash
cmake -S . -B build -DCMAKE_CUDA_ARCHITECTURES=native && cmake --build build -j16
nvidia-smi topo -m
nvidia-smi --query-gpu=index,pcie.link.gen.current,pcie.link.width.current --format=csv
./build/probe
./build/probe --bw
./build/bench_comm
./build/run_mig_path --gpus 0,2 --reps 10
./build/run_mig_path --gpus 0,1 --reps 10
```
