# WlA B1 粒度隔离（D1/D2 落地）：初步验证矩阵

日期：2026-10-15；平台：集群 PCIe4 4×3090（machine_state_*.txt 存证）；
参数：delta + prefix grp4/stp8；4 格 × 5 次 = 20 跑（每跑 8 模式，含 D1/D2）。
日志：results/wla_b1_20261015/。**性质 = 实现对 + 初步读数（n=5）**，
正式 X1 矩阵待规则冻结后按 7 次/格重跑。

## 1. 实现（wla_multigpu.cuh mode 6/7 + runner --with-b1）

对齐 WlB `multigpu.cuh` 的 B1 口径（`steal_req` 返回 1 / SIZE_MAX / batch）：

| 模式 | 引擎 | 分发 | 窃取粒度 k | 触发 |
|---|---|---|---|---|
| C (2) | C | 亲和 | 消费批（steal_batch=4） | 水位 + 空卡 |
| **D1 (6)** | **C** | 亲和 | **1**（one-steal） | 水位 + 空卡 |
| **D2 (7)** | **C** | 亲和 | **SIZE_MAX**（victim 一半） | 水位 + 空卡 |

`take = min(k, victim 盈余, victim/2+1)` 在 `steal_from` 内统一裁剪 ⇒
D1/D2 与 C **同引擎同通道同迁移成本**，唯一变量 = 粒度。触发逻辑三者逐字相同
（`pull_steal && mode != 1` 同一条件）⇒ 归因干净。
顺带修一处：撤回 A1 给 full 路径加的逐段 sync（曾改变 full 传输行为、
与去重矩阵不可比）；D2 多段由通道 ring 反压保护（submit 复用 slot 前
`cudaEventSynchronize`），无溢出风险。

## 2. Pooled（4 格 × 5 次 = 20）

| 模式 | makespan (ms) | steals | migr (MB) |
|---|---|---|---|
| ferry-C | 341.1 ± 19.3 | 8.9 | 105.2 |
| d1-one | 368.9 ± 44.6 | 12.5 | 148.2 |
| d2-half | 346.8 ± 23.8 | 9.9 | 136.0 |

- **C÷D1 = 1.085 ± 0.146**（>1 = D1 更慢 = 批粒度有净收益）
- **C÷D2 = 1.020 ± 0.090**（≈1，与 WlB 的 D2≈1.00 一致）

## 3. 关键：粒度收益**条件于偏斜存在**（复现 WlB 机制）

| 格 | C÷D1 | C÷D2 |
|---|---|---|
| steady/imbalanced | **1.151** | 0.994 |
| bursty/imbalanced | **1.251** | 1.132 |
| steady/balanced | 0.970 | 0.986 |
| bursty/balanced | 0.968 | 0.968 |

⇒ 偏斜档 D1 明显更慢（1.15–1.25×），平衡档 D1 与 C 无差（0.97×，无失衡
可纠、细粒度无对象）。**与 WlB 的 W6 结论（平衡档 C/D1 仅 1.02–1.08、
"粒度收益条件于偏斜"）同构**，在 WlA 主 regime 独立复现。

## 4. ⚠️ 口径纠正：WlA 的"粒度代价"不体现在 steals 上

**steals 只降 1.4×**（C=8.9 → D1=12.5），**远非 WlB 的 ↓175×**。原因：
WlA 的窃取单位本就是"请求级批"（48 请求、每跑仅 ~10 次窃取），不像 WlB
有 32768 个 pool 任务。**粒度代价在 WlA 体现为迁移字节**：

- D1 migr = 148.2 MB vs C = 105.2 MB（**+41%**）——细粒度窃取搬的是"最近
  到达"（更热、live 更多）的请求，且窃取次数更多 ⇒ 总字节上升。
- ⇒ **18.1③ 移除"减少窃取次数"判据是正确的**；WlA 的 B1 分解必须报
  **字节**与**makespan**，不能报 steals 降幅（那是 WlB 的故事）。
- 连带：18.4 对照列的 D1/D2 用途收敛为"把 C 相对基线的差异拆出粒度分量"，
  不承担"steals ↓"叙事。

## 5. 限制

- n=5/格（初步）；正式 X1 需 7 次/格并按 16.6 F3 预注册。
- C÷D1 pooled 1.085 ± 0.146（sem ≈ 0.033，距 1 约 2.6σ）——偏边缘；
  格内分解比 pooled 更清楚（偏斜两格 >1.15）。
- C 的 migr 在 WlA 有高方差（本矩阵 105MB vs 去重矩阵 152MB，均在 ±1σ 内），
  引用绝对值须带 std 并说明运行批次。
- D1/D2 只在 delta 模式验证；full/drop 未测（full 的段粒度语义与 delta 不同，
  需另判，暂不主张）。

## 6. 对实验设计的连带

- 18.4 对照列的 D1/D2 **已可用**（不必删除两列）。
- 粒度分解的**主指标 = migr/makespan**，`steals` 仅作参考（WlA 下不敏感）。
- "粒度收益条件于偏斜"在 WlA 复现 ⇒ 可作为跨 workload 的一般规律引用
  （WlB W6 + WlA 本矩阵两处独立证据）。
