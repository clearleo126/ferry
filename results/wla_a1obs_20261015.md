# A1 可行性判定：B_eff 在位观测 + mig-bw 敏感性扫描（只观测不决策）

日期：2026-10-15；平台：集群 PCIe4 4×3090（空闲窗口）；目的：回答
"A1（争用进规则）值不值得做"——判定数据，非论文矩阵（n 小，见限制）。

## 1. 加了什么（零决策影响）

- **B_eff EMA**（[A1-obs] 行）：steal_from 传输段计时（含 idx memcpy/gather/
  submit/sync/scatter 全窗口）→ 仅饱和 chunk（≥4MB）更新 EMA（首测直填，
  0.7/0.3）。
- **P(t)**：per-GPU 回填在途遥测（C 引擎 refill 批 submit→wait_last_arrival
  窗口 +/−）→ 决策时刻其余卡（v/g 双侧出 tick，自身不回填）在途回填 MB。
- E/C/门控逻辑零改动；对照跑数字在既有区间（回归 OK）。

## 2. 观测一：在位 B_eff（4 格 × 3 次，delta grp4/stp8）

| 量 | 读数 |
|---|---|
| C 的 B_eff EMA | **12.66–15.18 GB/s（中位 ≈14.6）**，跨格跨次稳定 |
| E 的 B_eff EMA | 0–13.95（观测饥饿：E 窃取少、chunk 常 <4MB；一次 0 obs） |
| P(t)（决策时刻并发回填） | **mean 0.4–1.1 MB，max 1.0–3.5 MB**（vs 单次迁移 20–150MB） |
| 三个"带宽"数对照 | 11.0（probe，full 段时代，E 的常数）｜16.6（v10 离线微基准，delta 批量化 24MB）｜**14.6（在位 EMA 中位）** |

## 3. 观测二：mig-bw 敏感性扫描（E 的成本常数轴，2 格 × {8,11,14.6,17.9} × 2 次）

| mig-bw | E migr 均值 (MB, n=4) | E/C makespan 均值 |
|---|---|---|
| 8.0 | 45.6 | 0.98 |
| 11.0 | 49.8（含一次 121 离群，方差大） | 0.99 |
| 14.6 | 87.3 | 0.97 |
| 17.9 | 86.9 | 0.94 |

C 的 migr 逐跑 51–250MB（水位策略 + 到达动态，本身高方差）。
steady/imb bw=14.6 r1 出现一次 E(76.2) > C(51.5) 反转（n=2，方差级，不主张）。

## 4. 判定（A1 三问三答）

1. **争用真实存在吗？** 存在但形态是**准常数偏移**，不是相位变化信号：
   在位 14.6 vs 离线 16.6 ≈ −12%（含 chunk 尺寸混淆，见限制）＝共享通道
   争用税的量级；而决策时刻 P(t) ≤3.5MB——回填批小（1–4MB）且窗口短，
   在决策瞬间信道里几乎没有排队的回填。⇒ **L2 的 κ·P(t) 前瞻项在该
   regime 几乎不会触发 → 降级为负结果**（诚实结论：决策时刻争用信号弱，
   争用表现为带宽均值的持久下移，恰好被 L1 式标定捕捉）。
2. **规则缺的是什么？** 不是"缺争用项"，是**常数过期**：E 的 11.0 沿用
   full 段时代的 probe 口径，从未对 v10 后的 batched-delta 路径重标定
   （离线 16.6 / 在位 14.6）→ 保守 ~30%。
3. **修常数的代价？** 成本估计降 30% ⇒ E 的过滤阈值放松 ⇒ **迁移量
   翻倍（46→87MB）而 makespan 全程平坦**（0.94–0.99，跨 2.2× 成本
   范围）。⇒ 两层含义：
   - **"−65% 迁移节省"部分站在成本高估上**（保守堆叠：过期常数 +
     去重未入账（E 成本按每请求 live 求和，重复计同组共享槽，dup 40–50%）
     + margin=2）。扫描量化了第一层 ≈2×。
   - **正向读法**：makespan 对阈值位置不敏感（平坦高原）＝ 16.2 的
     ε-预算框架（T_policy/T_C ≤ 1+ε 内尽量少迁）天然成立——阈值可以
     为"省字节"调，性能代价为零。这本身是可报告的 Pareto/敏感性结论。

## 5. 对 X1/X2/B2 的连带

- **X2 预演**：mig-bw 扫描 = 政策级成本错估轴（零代码）；X2 虚拟通道 =
  通道级真实代价轴。两者互补，前者数据已在手。
- **B2（争用无专门测量）部分补上**：在位 B_eff（17.9→14.6 的在位-离线差 +
  跨格方差）就是"迁移与回填共享通道"的直接测量，可直接引作 18.2 的证据。
- **A1 的最终形态建议**：争用以"**标定常数 + 敏感性曲线**"进规则与论文
  （L1 精髓），放弃 L2 快变前瞻项；E 的常数须声明口径并在去重后重标。

## 6. 限制

- n=3（观测）/ n=2（扫描）——判定级数据；入论文须 7 次/格且扫 4 格。
- 在位 vs 离线差被 chunk 尺寸混淆（在位 ≥4MB vs 离线 24MB，小 chunk
  每次开销占比更高）；精确分离需离线 4MB 档复测（F1 微基准可顺带）。
- E 的 EMA 观测饥饿（每 mode 独立 ctx，只有自己的迁移更新）；真实系统
  应全局共享遥测（C 的迁移也喂 E）——设计注记。
- E/C 的 run-to-run 方差大（bursty 尤甚），2 次均值的格间比较不可靠。
