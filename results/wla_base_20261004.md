## 2. ⚠️ 关键发现：RR 支配一切运行时重分配（本批最重要的结论）

**round-robin 分发在四格全部显著快于 C/E/LLX（imb 档快 9–18%），且零迁移。**

机理拆解：
- 本模型的失衡由 **dest 偏斜 rng 制造**（80% 请求落前一半卡），而
  **遵守 dest 没有任何收益**——full 模式下 refill 由全局 trace LRU 预生成
  （设计不变量：refill_bytes 各模式恒等 1242.97MB），请求在哪个卡执行不
  改变 miss 序列。
- 于是"RR：无视 dest 均匀分发"**在分发时刻零成本地消掉了全部失衡**；
  C/E/LLX 尊重 dest 再用 D2D 迁移纠偏 = 付迁移成本买"本可不存在的均衡"。
- 与 WlB 的 B2 空转（⑧⑨）同构：**决策的收益侧没有建模，只剩成本侧**。

推论（对论文主线，诚实且必须处理）：
1. WlA 的"C/A 9.18×"叙事**不能单独成立**——A 的失衡是合成分发制造的，
   外部基线（RR）证明"分发级均匀化"比"运行时迁移"更优。审稿人一句
   "为什么不直接 round-robin dispatch"即可击穿。
2. **迁移的价值只在"分发必须尊重局部性"的 regime 存在**：即 C2（前缀
   亲和）——请求的热块已在 home 卡被同前缀请求暖过，发到别的卡要冷启动
   回填。此时 RR 要付 refill 代价，A 要付失衡代价，C/E/LLX 在
   "亲和收益 vs 均衡收益"间做真正的权衡。**C2 由叙事缺口升级为结构必需。**
3. 实现 C2 后本矩阵须重跑：预期 RR 的 refill 显著高于 C/LLX（冷启动账），
   亲和系模式在 imb 档反超。

## 3. 次级观察（不受 C2 影响、可直接用）

- **LLX vs C**：四格 LLX ≤ C×1.12，且迁移量仅为 C 的 23%（171 vs 727MB）、
  窃取次数 1/4 —— 全局周期重平衡与分布式水位窃取在该 regime 等效甚至
  更省；LLX 复刻实现本身通过反证自检（balanced 档 LLX 343 vs RR 330 ≈）。
- **E 的均衡质量**：imb 0.017（C 0.357），是亲和系模式中最优（值过滤
  偏好高剩余工作请求 → 每字节迁移承载更多工作）。
- **迁移量-性能单调性**（亲和系内部）：RR 0MB < LLX 171 < E 514 < C 727，
  makespan 同向 337 < 357 < 390 < 393 —— 迁移越多越慢，与本模型
  "迁移无收益侧"一致，可作 C2 前后的对照基线（C2 后该单调性应反转）。
