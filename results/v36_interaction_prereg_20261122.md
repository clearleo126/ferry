# v36 2×2 全因子交互检验（互补性）：预注册，2026-11-22 跑前写死

## 0. 目的

§37 的机制结论是"**便宜握手 × 体积准入是互补品**"，但它是从**四组不同 n 的
非平衡数据**上读出来的（n=12/12/12/30，且限流档 140 与 220 混用）。本轮用
**同一批、同一预算、同一 n** 的 2×2 全因子把它变成可检验的交互项。

## 1. 设计（先写死）

- 平台/COMMON/trace 与 §37 逐字一致；场景 `full`（g=1 ×3.0 @0）。
- 因子：`--mvcc {0,1}` × `--mig-rate-mbps {0, 220}`（220 = §37 校准点）。
- **4 格 × n=30 = 120 格**；逐 rep 内四格轮转，顺序按 rep 奇偶翻转。
- **主分析列 = C 列**（`cost_filter=false`，见 §37.3 列语义）：令牌桶对所有
  模式生效，故 C 列 = `mvcc + 限流`，成本过滤是**常量** ⇒ 能干净分离本轮的
  两个因子。E 列（含成本过滤）作为辅证一并报。
- 预算**只取 220**（140 已由 §35 判过度限流），不做扫描。

## 2. 判据（预注册，跑后不得改）

记 C 列 makespan，四格中位：`A=m0_bOff`、`B=m1_bOff`、`C0=m0_bOn`、`D=m1_bOn`。

1. **I1 交互项（主）**：逐 rep 算 `I = (D−C0) − (B−A)`。
   成立：**中位 ≤ −200ms** 且 **≥20/30 为负** 且 **95% CI 上界 <0**。
   （这是"互补性"成为可写主张的唯一凭据。）
2. **I2 单因子不显著**：`B−A`（纯 mvcc）与 `C0−A`（纯限流）的中位 CI 均跨 0
   或为正 ⇒ 支撑"缺一不可"。若其中之一显著为负，则改写成"某单一因子即有效"，
   并撤下互补性主张。
3. **I3 组合格最优（C 列）**：`D−A` 中位 ≤ **−150ms**、≥22/30、CI 上界 <0。
4. **I4 退化格**：`C0−A`（慢握手 + 限流）**≥20/30 为正**（限流脱离快握手会变差）。
5. **I5 体积单调**：迁移字节 `A > B ≥ D`，且 `D ∈ A ± 15%`。
6. **I6 steal_ms（C 列）**：`B` 与 `D` 均 ≤ 0.6×`A`；`C0` ≥ `A`。
7. **I7 正确性**：120 格 `[audit] step_mismatch` 全空；无挂起/超时。
8. 统计纪律：配对差 + 确定性字节账为主张依据；比值仅方向。
   **n=30 的 t 临界值 2.045（df=29）**。

## 3. 与 §37 的关系

- §37 的既有数据（v35 72 格 + v35b 36 格）**保留**，但本轮的 120 格是
  同批同 n 的干净版本；**主张以本轮为准**，§37 作为其前置探索。
- 若 I1 与 §37 §6.4 的 −474ms（n=12、CI 跨 0）方向一致且本轮显著
  ⇒ 互补性从"方向清楚"升为"成立"。
